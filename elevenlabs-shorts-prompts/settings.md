# Настройки

## Voice Design (создание голоса)

| Параметр | Рекомендация | Зачем |
|---|---|---|
| Guidance Scale | 28–35 | Держит быстрый темп и молодой тембр. Выше 40 иногда «ломает» качество |
| Loudness | чуть выше середины | Shorts / Reels читаются с телефона |
| Preview length | 400–800 знаков | Короткие фразы дают дёрганый голос |

Если голос слишком «актёрский / мультяшный» — Guidance 22–26.  
Если слишком взрослый / дикторский — Guidance 32–38 и карточки `01`, `07`, `11`.

## После сохранения (Text to Speech)

### Eleven v3

Лучше для хуков, смеха, «стопе», эмоций. Используй теги из `tts-scripts-v3/`.

| Слайдер | Shorts-энергия | Спокойнее |
|---|---|---|
| Stability | 30–42 | 50–60 |
| Similarity | 70–80 | 80–88 |
| Style | 20–35 | 0–15 |
| Speaker boost | On | On |
| Speed | 1.05–1.12 | 1.00 |

### Multilingual v2 / Turbo

Если v3 слишком «играет»:

- Stability 40–50
- Style 0–20
- Speed 1.08–1.15 (темп добираешь скоростью, не криком в тексте)

## Как писать текст ролика

- Первые 8–12 слов — крючок
- Короткие фразы, точки, не запятые-простыни
- CAPS только на 1–2 словах, не на всём абзаце
- Теги v3: `[excited]`, `[laughs]`, `[whispers]`, `[sarcastic]` — по одному, не пачкой
