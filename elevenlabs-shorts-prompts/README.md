# ElevenLabs: молодой харизматичный голос, быстрый темп (Shorts / Reels)

Пак промптов для **Voice Design** — оригинальный взрослый голос 22–26, быстрый как в коротких вертикальных видео, харизматичный, без имён знаменитостей и без «подростка».

Собрано так, чтобы с большей вероятностью пройти правила ElevenLabs: https://elevenlabs.io/use-policy

## С чего начать

1. Прочитай `HOW-TO.md`
2. Возьми одну карточку из `voice-design/`
3. Если фильтр отклонил — бери `voice-design/compact/`
4. После сохранения голоса озвучивай скриптами из `tts-scripts-v3/`
