# Папка материалов

Сюда складываешь всё, из чего собираются видео. Содержимое в git не попадает.

```
assets/
├─ prompts/
│  ├─ voices/       # .txt — текстовые промпты для создания голосов (Voice Design)
│  └─ scripts/      # .txt — тексты для озвучки (можно с маркерами [[слово]] для подсветки)
├─ backgrounds/     # .mp4/.mov — фоны-футажи
├─ emojis/          # .png/.webp/.gif — эмодзи для комбо-анимаций
├─ sounds/          # .mp3/.wav — swoosh и другие звуки (3 звука)
├─ qr/              # .png — qr-коды
├─ music/           # .mp3/.wav — фоновая музыка (опционально)
├─ fonts/           # .ttf — шрифт «блок» для субтитров (subtitle.ttf)
└─ voiceovers/      # сюда софт кладёт готовую озвучку (mp3 + json с таймингами)
```

Маркеры в тексте скрипта:
- `[[слово]]` — подсветить слово цветом (ключевые слова);
- `[emoji:имя]` — вставить эмодзи `assets/emojis/имя.png` с комбо-анимацией в этом месте.

Режимы папок задаются в `config.yaml` (`folders.<имя>.mode`):
- `cycle` — используются все файлы по кругу;
- `consume` — использованный файл удаляется из папки.
