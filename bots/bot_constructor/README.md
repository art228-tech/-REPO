# 🤖 Бот-конструктор приветок

Telegram-бот, который позволяет создавать "приветки" — ботов, пишущих новым подписчикам канала по заданному сценарию.

В сценарии три типа шагов:
- 🎰 **Рулетка** — кнопка с миниапп-рулеткой. Юзер крутит — всегда выпадает 5000⭐ — забирает приз → сценарий идёт дальше.
- 📢 **Обязательная подписка (ОП)** — спонсорские каналы с кнопкой "Проверить". Если уже подписан — шаг автопроходит.
- 💬 **Сообщение** — текст / фото / гифка / стикер / переслать пост + кнопки + три варианта ожидания (none / timer / user_message).

## Возможности

- ✅ Несколько приветок одновременно (каждая со своим токеном)
- ✅ Реакция на `chat_join_request` (заявка в канал) + `/start`
- ✅ Поддержка форматирования (жирный, курсив, спойлеры, цитаты, премиум-стикеры)
- ✅ Любой контент: фото, гифки, стикеры, видео, документы, переслать пост
- ✅ Цветовые префиксы кнопок (17 цветов через эмодзи — TG не даёт менять цвет inline-кнопок напрямую)
- ✅ Дублирование зависшего юзера: интервал + прирост + максимум
- ✅ Автоудаление старого сообщения при переходе
- ✅ Реф-ссылки с отдельной статистикой
- ✅ Подробная статистика: все / премиум / мёртвые / по шагам / по реф-ссылкам
- ✅ Массовая рассылка с авто-пометкой заблокировавших
- ✅ Премиальная WebApp-рулетка (canvas + анимации + конфетти)

## Быстрый старт (локально, без рулетки)

```bash
# 1. Клонировать/распаковать в /opt/bot или куда удобно
cd /opt/bot

# 2. Установить зависимости (Python 3.10+)
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt

# 3. Скопировать .env.example → .env и заполнить
cp .env.example .env
nano .env   # вписать BOT_TOKEN, ADMIN_IDS

# 4. Запустить
python main.py
```

Без HTTPS-домена рулетка не откроется (Telegram её не пропустит), но всё остальное (ОП, сообщения, статистика, рассылки) будет работать.

## Как пользоваться

1. Запусти бот, открой его в Telegram, нажми /start (твой Telegram ID должен быть в `ADMIN_IDS`).
2. **Мои приветки** → **➕ Добавить** — пришли токен новой приветки от @BotFather.
3. После добавления:
   - Сделай приветку **админом канала** с правом "пригласительные ссылки" — иначе она не увидит заявки.
4. **Открой приветку** → **📜 Сценарий** → **➕ Добавить шаг** → выбери тип.
5. Анкета проведёт через все настройки.
6. **⚙️ Настройки** — задержка перед началом, таймер удаления старых сообщений.
7. **🔗 Реф-ссылки** — генерируй ссылки вида `https://t.me/yourbot?start=ref_AbCdEf`.
8. **📊 Статистика** — смотри прохождения, фильтруй по live/dead/premium.
9. **📣 Рассылка** — массовая рассылка по живым.

## Цвета кнопок

Telegram **не позволяет** менять цвет inline-кнопок напрямую через API. Мы делаем "цвет" через эмодзи-префикс. Так что кнопка с цветом `green` получает префикс `🟢`. Это стандартная практика и хорошо смотрится визуально.

17 цветов: default / red / orange / yellow / green / blue / purple / pink / cyan / brown / black / white / fire / star / heart / lightning / crown.

## Troubleshooting

- **Приветка не реагирует на заявку** — проверь, что она админ канала и имеет право на пригласительные ссылки.
- **Рулетка не открывается** — `WEBAPP_URL` должен быть HTTPS. На локалке тестировать рулетку нельзя.
- **Спонсорский канал "проверка не работает"** — приветка должна быть админом канала, иначе `get_chat_member` упадёт.
- **TelegramRetryAfter** — Telegram ограничивает скорость; рассылки идут по 25 шт/сек.
- **`Database is locked`** — на одну SQLite-БД должен работать один процесс. Не запускай `python main.py` дважды.
