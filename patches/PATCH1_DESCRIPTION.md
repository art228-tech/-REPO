# Патч 1 — не существует как готовый файл

Этот «патч» делался **в самой первой деплой-сессии** (19-21 мая) серией ручных
правок и не сохранился как один `apply_patch1.py`. Он содержит ранние фиксы,
которые применялись прямыми `str_replace` в коде:

1. **FSInputFile для фото** — конструктор скачивал фото на диск, приветка
   отправляла с диска через `FSInputFile`, а не пересылала `file_id` напрямую
   (когда у приветок разные токены, file_id с конструктора не работает у
   приветки).

2. **Премиум-рулетка** — для шага типа `roulette` добавлен флаг `is_premium`
   в config, при `True` рулетка использует увеличенный выигрыш и премиум-стикер
   вращения.

3. **Нативные цвета кнопок** — переход от своих кодов (default/secondary) к
   `style`-полю aiogram 3.7+ (primary/success/danger/warning).

## Если собираешь конструктор с нуля по ТЗ

Все эти три пункта уже **должны быть встроены в код** изначально — они часть
правильной архитектуры:
- `FSInputFile` при отправке фото из БД
- `is_premium` в роулетке как опция
- `style` для цвета кнопок

В новом проекте отдельным патчем 1 их применять **не нужно** — они должны
быть в исходном коде.

## Если применяешь патчи к старой версии 19 мая

Нужно вручную:
1. Найти в `bots/greeter.py` или `bots/scenario.py` отправку фото →
   `await bot.send_photo(chat_id, FSInputFile(path), ...)` вместо file_id.
2. В роулетке (`_send_roulette_step`) добавить ветку для `cfg.get("is_premium")`.
3. В клавиатурах заменить кастомные цвета на `style="primary"|"success"|...`.

Эти изменения слишком разбросаны по коду чтобы оформить их единым автоматическим
скриптом — поэтому в моих архивах их нет как `apply_patch1.py`.
