# Озвучка ElevenLabs

Программа для Windows, которая создаёт голоса по текстовым описаниям и озвучивает ими пакет текстов через официальный API ElevenLabs.

Схема работы: в одной папке лежат промпты голосов, в другой — тексты. Программа создаёт голоса через Voice Design, а затем раздаёт их текстам по кругу и работает, пока не кончатся тексты или кредиты.

## Скачать

**[ElevenLabsVoiceover-windows.zip](https://github.com/art228-tech/-REPO/releases/download/windows-latest/ElevenLabsVoiceover-windows.zip)** — распаковать и запустить `ElevenLabsVoiceover.exe`. Python не нужен, внутри уже лежат готовые папки `промпты`, `тексты`, `готово` с примерами.

Если папки уже есть, можно взять только программу: **[ElevenLabsVoiceover.exe](https://github.com/art228-tech/-REPO/releases/download/windows-latest/ElevenLabsVoiceover.exe)**.

Сборка обновляется автоматически при каждом изменении кода. Windows SmartScreen может предупредить о неизвестном издателе — программа не подписана сертификатом, нажмите «Подробнее» и «Выполнить в любом случае».

## Что она умеет

- **Создаёт голоса по описанию.** Каждый `.txt` в папке промптов — это описание одного голоса («спокойный мужской баритон, размеренный темп»). Программа отправляет его в Voice Design, сохраняет все три предложенных варианта на диск, чтобы их можно было послушать, и добавляет первый в ваш аккаунт.
- **Раздаёт голоса по кругу.** Первый текст читает первый голос, второй — второй, третий — третий, четвёртый снова первый. Есть второй режим: озвучить каждый текст всеми голосами сразу.
- **Продолжает с места остановки.** Готовые куски запоминаются, и повторный запуск не платит за них заново. Обрыв связи, закрытое окно или кончившиеся кредиты не приводят к потере сделанного.
- **Следит за балансом.** Перед стартом показывает, сколько кредитов уйдёт, во время работы сверяется с сервером и останавливается сама, не уходя в минус. Можно задать неприкосновенный запас.
- **Режет длинные тексты по границам предложений** и склеивает обратно в один файл, передавая соседние куски модели как контекст — чтобы интонация на стыках не рвалась.
- **Ведёт подробный журнал** и умеет собирать всё нужное для разбора проблемы в один zip. API-ключ из журналов и отчётов вырезается автоматически.

## Что нужно

- **Windows** (программа работает и на macOS с Linux, но рассчитана на Windows).
- **Python 3.9 или новее.** Скачать: [python.org/downloads](https://www.python.org/downloads/). При установке обязательно отметьте галочку **«Add python.exe to PATH»**.
- **Аккаунт ElevenLabs** — подойдёт бесплатный.
- **ffmpeg** — не обязателен. Без него MP3 всё равно склеиваются встроенным способом. Нужен только если выберете формат WAV или OPUS: тогда положите `ffmpeg.exe` рядом с программой.

## Получение API-ключа

1. Откройте [elevenlabs.io/app/developers/api-keys](https://elevenlabs.io/app/developers/api-keys) и войдите в аккаунт.
2. Нажмите **Create Key**.
3. **Важно.** По умолчанию ключ создаётся ограниченным, и вы должны сами отметить, что ему разрешено. Включите как минимум **Text to Speech**, **Voices** и **User** — либо просто переключите тумблер **Restrict Key**. Если этого не сделать, программа будет получать ошибку «Ключу не хватает прав».
4. Скопируйте ключ сразу: полностью он показывается только один раз.

## Быстрый старт

1. Скачайте или распакуйте эту папку.
2. Создайте три папки, например:
   - `C:\Озвучка\промпты` — описания голосов;
   - `C:\Озвучка\тексты` — что озвучивать;
   - `C:\Озвучка\готово` — куда складывать результат.
3. Положите в первые две по несколько `.txt`. Готовые примеры лежат в папке `samples`.
4. Запустите **`run.bat`**. При первом запуске он сам создаст окружение и поставит зависимости — это займёт около минуты.
5. В окне вставьте API-ключ и нажмите **Проверить**. Появится ваш тариф, остаток кредитов и число свободных слотов для голосов.
6. Укажите три папки кнопками **Обзор…**. Под ними сразу появится оценка: сколько будет файлов и во сколько кредитов это обойдётся.
7. Нажмите **Начать озвучку**.

## Как писать промпты голосов

Промпт — это обычный `.txt` с описанием голоса. Имя файла становится именем голоса, поэтому удобно называть их `1-диктор.txt`, `2-ведущая.txt` и так далее: порядок файлов задаёт порядок раздачи.

ElevenLabs рекомендует такую структуру:

```
Native <язык>. <пол>, <возраст>. <уровень качества>.
Persona: <2–5 слов>. Emotion: <2–3 прилагательных>.
<1–2 предложения о тембре, темпе и манере подачи>
```

Живой пример:

```
Native Russian. Male, 35-45. Studio quality.
Persona: спокойный документальный диктор. Emotion: уверенный, тёплый, доброжелательный.
Низкий грудной тембр с мягкими согласными и ровным дыханием. Читает размеренно,
с отчётливыми паузами между смысловыми блоками, без нажима и без театральности.
```

Что стоит учитывать:

- **Указывайте язык и региональный вариант в первом предложении** — иначе модель уплывает в другой акцент.
- **Уровни качества** работают как ключевые слова: `Ok quality`, `Good quality`, `Very good quality`, `Excellent quality`, `Studio quality`, `Broadcast quality`.
- **Не пишите «accent», если имеете в виду интонацию** — это переключает диалект. Описывайте ударения и манеру.
- **Избегайте слов про эффекты** («реверберация», «эхо», «телефон», «плёнка») — они портят результат.
- Слово «thick» для акцента работает лучше, чем «strong».

Полное руководство: [документация ElevenLabs по Voice Design](https://elevenlabs.io/docs/eleven-creative/voices/voice-design).

## Что появится в папке результатов

```
готово\
  пример-1.mp3          готовые озвучки, имя берётся от исходного текста
  пример-2.mp3
  _manifest.csv         таблица: какой файл каким голосом озвучен
  _voices\
    1-диктор\
      variant_1.mp3     три варианта голоса от Voice Design;
      variant_2.mp3     в аккаунт добавляется variant_1
      variant_3.mp3
```

Если вариант 1 не понравился — послушайте остальные, поправьте промпт, включите **Пересоздать голоса заново** и запустите снова.

## Сколько это стоит

Кредиты у ElevenLabs общие для сайта и API, но **через API дешевле**: на моделях Flash и Turbo списывается 0,5 кредита за символ вместо одного. Поэтому по умолчанию выбрана `eleven_flash_v2_5`.

| Что | Расход |
|---|---|
| Озвучка на Flash / Turbo | 0,5 кредита за символ |
| Озвучка на Multilingual v2 / v3 | 1 кредит за символ |
| Создание одного голоса | столько кредитов, сколько символов в «тексте прослушивания» |

Создание голоса тарифицируется **один раз** за все три предложенных варианта. Текст прослушивания по умолчанию короткий, около 140 символов, — три голоса обойдутся примерно в 420 кредитов. На бесплатном тарифе с его 10 000 кредитов в месяц это заметная доля, поэтому голоса кэшируются и повторно не создаются.

Точную оценку для ваших папок программа показывает на вкладке **Работа** до запуска.

## Настройки

**Озвучка**

| Настройка | Смысл |
|---|---|
| Модель | Flash дешевле вдвое, Multilingual v2 качественнее. Список подтягивается из вашего аккаунта после проверки ключа |
| Формат файла | `mp3_44100_128` подходит всем. Битрейт 192 доступен от тарифа Creator, WAV и PCM — от Pro |
| Символов в куске | Меньше значение — меньше теряется при обрыве, но больше запросов. По умолчанию 2500 |
| Код языка | Пусто — определять автоматически. Можно задать `ru`, `en` и так далее |

**Параметры голоса**

| Настройка | Смысл |
|---|---|
| Стабильность | Ниже — шире эмоциональный диапазон, выше — ровнее и монотоннее |
| Схожесть | Насколько строго держаться исходного тембра |
| Выразительность | Усиление манеры. Любое значение выше нуля замедляет генерацию |
| Скорость речи | 1.0 — обычный темп |

**Создание голосов**

| Настройка | Смысл |
|---|---|
| Модель Voice Design | `eleven_multilingual_ttv_v2` универсальнее, `eleven_ttv_v3` новее |
| Точность промпта | Шкала 0–100, в API по умолчанию 5. Выше — строже по описанию, но звук искусственнее. В примерах ElevenLabs используют 25–40, начните оттуда, если голос выходит непохожим на промпт |
| Текст прослушивания | Фраза, которую произнесут созданные голоса в папке `_voices`. Именно за её длину списываются кредиты при создании голоса, 100–1000 символов |

**Бюджет и надёжность**

| Настройка | Смысл |
|---|---|
| Оставить в запасе | Кредиты, которые программа не потратит ни при каких условиях |
| Пауза между запросами | Сдерживает темп, чтобы не упираться в ограничение частоты |
| Повторов при сбое | Сколько раз повторять при обрыве связи или ошибке сервера |

## Если что-то пошло не так

**Ключ не вставляется в поле.** Нажмите кнопку **Вставить** рядом с полем — она берёт значение из буфера обмена напрямую. Работают также правая кнопка мыши по полю и обычное Ctrl+V, причём при любой раскладке клавиатуры.

**«Ключу не хватает прав»** — при создании ключа не отмечены нужные разрешения. Откройте [страницу ключей](https://elevenlabs.io/app/developers/api-keys), отредактируйте ключ и включите Text to Speech, Voices и User.

**«Свободных слотов для голосов нет»** — на бесплатном тарифе слотов немного. Удалите лишние голоса в личном кабинете или включите **Пересоздать голоса заново**: программа сама освободит те, что создавала раньше.

**«Кредиты на аккаунте закончились»** — работа останавливается аккуратно, сделанное сохраняется. Пополните баланс и запустите снова: озвучка продолжится со следующего куска.

**Вместо русского текста кракозябры** — программа сама определяет кодировку и понимает UTF-8, UTF-8 с BOM и Windows-1251. Если файл в чём-то более экзотическом, пересохраните его в UTF-8.

**Ничего не помогло.** Нажмите **Собрать отчёт о проблеме** — получится zip с журналами, настройками и сведениями о системе. API-ключ из него вырезан, файл можно отправлять как есть.

Журналы всегда лежат в `%APPDATA%\ElevenLabsVoiceover\logs`, там же настройки и база прогресса.

## Запуск из командной строки

Полезно для проверки настроек и работы по расписанию:

```bat
python app.py --check
python app.py --estimate --prompts C:\Озвучка\промпты --texts C:\Озвучка\тексты
python app.py --prompts C:\Озвучка\промпты --texts C:\Озвучка\тексты --output C:\Озвучка\готово
python app.py --report
```

Полный список ключей — `python app.py --help`.

## Сборка в один exe

Запустите **`build_exe.bat`**. Результат появится в `dist\ElevenLabsVoiceover.exe` и не требует установленного Python на целевой машине. Настройки и журналы всё так же хранятся в `%APPDATA%\ElevenLabsVoiceover`, поэтому обновление exe их не затрагивает.

---

## Хранение ключа и приватность

Ключ хранится в открытом виде в `%APPDATA%\ElevenLabsVoiceover\config.json`, как это принято у настольных утилит. Если так не годится:

- снимите галочку **Запомнить ключ на этом компьютере** — тогда его придётся вводить каждый раз;
- либо задайте переменную окружения `ELEVENLABS_API_KEY`, и программа возьмёт ключ из неё.

Рекомендую при создании ключа поставить на него лимит кредитов: тогда даже при утечке с него не спишут больше заданного.

Программа обращается только к `api.elevenlabs.io`. Никакой телеметрии и никаких других сетевых соединений.

## Разработка

```bash
pip install -r requirements.txt pytest
python -m pytest tests/ -q
```

Структура:

```
elevenlabs_voiceover/
  api_client.py    обращения к REST API, классификация ошибок, повторы
  runner.py        оркестратор: голоса, раздача по кругу, контроль кредитов
  chunker.py       нарезка текста по абзацам и предложениям
  state.py         SQLite: прогресс и кэш голосов
  audio.py         склейка кусков в один файл
  gui.py           окно на tkinter
  cli.py           консольный режим
  diagnostics.py   сбор отчёта о проблеме
  logging_setup.py журналы с вырезкой ключа
  config.py        настройки
```
