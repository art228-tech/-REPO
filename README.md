# AutoShorts

Автоматизация коротких вертикальных видео: **озвучка** (ElevenLabs через Dolphin
Anty или официальный API) и **монтаж** по фиксированному шаблону (CapCut на
Windows или headless-рендер FFmpeg). Озвучка и монтаж — два независимых процесса,
запускаются отдельно, каждому можно задать число циклов.

> Озвучка работает с **одним твоим аккаунтом** ElevenLabs. Автосоздания и
> ротации нескольких аккаунтов для обхода лимитов бесплатного тарифа тут нет.

## Возможности

- Создание голосов из текстовых промптов (Voice Design) — по умолчанию 3 голоса.
- Генерация озвучки с таймингами слов → синхронные субтитры без ручной подгонки.
- Обработка лимитов ElevenLabs (длинный промпт/текст режется, а не роняет софт).
- Папки-категории с режимами `cycle` (по кругу) и `consume` (использовал → удалил).
- Учёт использованных секунд фона: каждое видео берёт следующий отрезок.
- Монтаж по слоям: блюр-фон + основной фон (~5:6) + субтитры («Сияние») +
  эмодзи с комбо-анимациями + swoosh + QR в конце.
- Crash-safe: прогресс пишется атомарно, после сбоя запуск продолжается без потерь.
- Подробные логи в `logs/` для быстрого разбора багов.

## Структура

```
src/autoshorts/
├─ config.py          # загрузка/валидация config.yaml
├─ logging_setup.py   # логи в консоль и файл
├─ state.py           # crash-safe состояние (атомарный JSON)
├─ assets.py          # менеджер материалов + нарезка фонов
├─ subtitles.py       # генерация .ass (стиль «Сияние», тайминг по словам)
├─ voice/
│  ├─ base.py         # интерфейс провайдера + утилиты лимитов
│  ├─ dolphin.py      # Dolphin Anty (браузер, один аккаунт)   [Windows]
│  ├─ elevenlabs_api.py  # официальный API
│  └─ pipeline.py     # оркестратор озвучки
└─ montage/           # сборка видео (CapCut / FFmpeg)          [в разработке]
```

## Установка

```bash
python -m venv .venv && . .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium                    # для Dolphin-провайдера
# только на Windows (авто-экспорт CapCut):
pip install -r requirements-windows.txt
```

## Настройка

```bash
cp config.example.yaml config.yaml
cp template.example.yaml template.yaml
```

Заполни `config.yaml` (провайдер озвучки, папки, режимы) и положи материалы в
`assets/` (см. `assets/README.md`).

## Запуск

Озвучка и монтаж запускаются раздельно; `--cycles` задаёт число прогонов:

```bash
python -m autoshorts.cli voice   --cycles 5
python -m autoshorts.cli montage --cycles 5
```

Или через десктопный интерфейс (в разработке): `python -m autoshorts.cli gui`.

## Тесты

```bash
python -m pytest tests/ -q
```
