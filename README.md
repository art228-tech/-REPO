# ElevenLabs Auto Voiceover (Dolphin Anty)

Софт для **автоматической озвучки в ElevenLabs** через антидетект‑браузер **Dolphin{anty}**.

Сценарий работы (полностью автоматический):

1. Перед запуском вы выбираете папки: куда скачивать озвучки, откуда брать **промпты для голосов** и откуда брать **тексты для озвучки**. Указываете прокси и Google‑аккаунт.
2. Софт авторизуется в Dolphin Anty, **создаёт профиль** и привязывает к нему указанный **прокси**.
3. Запускает профиль с автоматизацией (CDP) и подключается к нему через Puppeteer.
4. Заходит на ElevenLabs и **входит через Google** (email + пароль, при необходимости 2FA/TOTP).
5. **Создаёт голоса** (Voice Design) по промптам из папки — по умолчанию 3 голоса. Промпты берутся **по кругу**: когда список заканчивается, чтение продолжается с начала.
6. Переходит в **Text to Speech**, выставляет настройки (по умолчанию или заданные вами) и **озвучивает тексты**. Каждый текст берётся **один раз** и после успешной озвучки **удаляется** из папки. Голоса используются **по кругу**.
7. Работает, пока **не закончатся токены (кредиты)** ElevenLabs или тексты.
8. По завершении **закрывает и удаляет профиль** Dolphin.

Есть **живой отстук логов** в веб‑интерфейсе и кнопка **скачать логи в файл**, чтобы прислать их для разбора.

> ⚠️ Важно: автоматизация подключается к **вашему** приложению Dolphin{anty}, которое должно быть **запущено и авторизовано**. Автоматизация профилей доступна только на **платном тарифе** Dolphin. Селекторы ElevenLabs/Google вынесены в один файл и легко правятся, если сайт изменит вёрстку (см. раздел «Если что‑то сломалось»).

## Требования

- **Node.js ≥ 20** (проверено на Node 22).
- Установленный и запущенный **Dolphin{anty}** (десктоп‑приложение) на этой же машине.
- **API‑токен Dolphin** — из личного кабинета `https://dolphin-anty.com/panel`, раздел API.
- Google‑аккаунт для входа в ElevenLabs и рабочий **прокси**.

## Установка

```bash
npm install
cp .env.example .env   # при желании поправьте порт/пути
```

## Запуск (веб‑интерфейс)

```bash
npm run dev      # режим разработки (авто‑перезапуск)
# или
npm start        # обычный запуск
```

Откройте в браузере: **http://localhost:4599**

В интерфейсе:

- выберите три папки (кнопка «Обзор» открывает файловый навигатор);
- заполните токен Dolphin, прокси, Google‑аккаунт, параметры голосов и озвучки;
- нажмите **Сохранить**, затем **Запустить**;
- следите за статусом и логами в правой панели, при необходимости — **Скачать логи**.

## Сухой прогон (без токенов) — рекомендуется для теста

Включите галочку **«Сухой прогон (симуляция)»** или запустите:

```bash
npm run cli -- --dry-run
```

В этом режиме Dolphin и ElevenLabs **не используются** — работают встроенные симуляторы: создаются файлы‑заглушки озвучки, ведётся учёт «кредитов», тексты удаляются, профиль «создаётся/удаляется». Это позволяет проверить весь сценарий, папки, удаление текстов и логи, **не тратя реальные токены**.

## Формат папок

- **Промпты голосов** — текстовые файлы (`.txt`, `.md`). Содержимое файла = описание голоса для Voice Design. Ограничение ElevenLabs: **20–1000 символов**. Слишком короткие отбраковываются (голос не создастся), слишком длинные — **автоматически обрезаются** по границе слова.
- **Тексты озвучки** — текстовые файлы (`.txt`, `.md`). Каждый озвучивается один раз и удаляется. Очень длинные тексты автоматически бьются на части.
- **Папка скачивания** — сюда сохраняются аудиофайлы вида `<имя_текста>__<имя_голоса>.mp3`.

Примеры лежат в `samples/prompts` и `samples/texts`.

```bash
npm test          # запуск всех тестов (vitest)
npm run typecheck # проверка типов
```

Покрыты: валидация промптов и лимитов ElevenLabs, разбиение текста, циклическая очередь промптов, «расходная» очередь текстов с удалением, валидация конфигурации, TOTP (по эталонным векторам RFC 6238), клиент Dolphin (замоканный HTTP), логгер с маскировкой секретов и **полный сценарий оркестратора на симуляторах** (happy‑path, цикл голосов, остановка по кредитам, пропуск плохого промпта).

## Архитектура

```
src/
  config/        схема (zod) + хранение конфигурации
  logging/       логгер: буфер, файл сессии, стрим по WS, маскировка секретов
  queue/         promptQueue (по кругу) и textQueue (расход + удаление)
  dolphin/       localApi (:3001), remoteApi (dolphin-anty-api.com), сервис, симулятор
  elevenlabs/    вход через Google, Voice Design, TTS, скачивание, симулятор, TOTP
  core/          orchestrator — весь сценарий
  server/        Express + WebSocket + файловые хелперы
public/          веб‑интерфейс (config + мониторинг + логи)
tests/           модульные и интеграционные тесты
```

Ключевые детали, учтённые для стабильности:

- **Лимиты Voice Design**: описание 20–1000 символов, preview 100–1000; авто‑обрезка/валидация до отправки, чтобы голос не «падал» по ограничению.
- **Исчерпание кредитов**: определяется как по остатку на странице usage, так и по тексту ошибки при генерации (`OutOfCreditsError`) → корректное завершение и удаление профиля.
- **Ретраи** сетевых операций Dolphin с экспоненциальным бэкоффом.
- **Скачивание** настраивается через CDP `Browser.setDownloadBehavior`; файл дожидается стабилизации размера, затем переименовывается.
- **Безопасность логов**: пароли/токены маскируются.

## Как это подключается к Dolphin Anty

1. Локальный API (`POST /v1.0/auth/login-with-token`) — авторизация по токену.
2. Remote API (`POST /browser_profiles`) — создание профиля с прокси.
3. Локальный API (`GET /v1.0/browser_profiles/{id}/start?automation=1`) — старт с CDP, возвращает `port` и `wsEndpoint`.
4. Puppeteer подключается к `ws://127.0.0.1:{port}{wsEndpoint}`.
5. По завершении — `stop` (локально) и `DELETE /browser_profiles/{id}` (remote).

## Если что‑то сломалось (селекторы)

UI ElevenLabs и Google периодически меняется. Все селекторы и текстовые метки собраны в
`src/elevenlabs/selectors.ts` — для каждого действия хранится несколько вариантов, которые
перебираются по очереди. Если шаг перестал срабатывать: включите сухой прогон для проверки логики,
скачайте логи (кнопка в UI) и обновите соответствующие селекторы.

## Ограничения

- Требуется запущенный Dolphin{anty} и платный тариф с автоматизацией.
- Вход через Google может требовать подтверждения на доверенном устройстве; для 2FA укажите TOTP‑секрет в настройках.
- Реальные шаги в браузере не покрываются автотестами (нет доступа к аккаунту/боту в CI); для них предусмотрен сухой прогон и подробное логирование.
