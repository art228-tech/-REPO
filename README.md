# CapCut Автомонтаж

Софт для автоматического монтажа коротких видео на базе готового проекта
**CapCut (Windows, русский интерфейс)**. Ядро откалибровано по реальному
проекту пользователя: CapCut **9.0.0**, вертикальный формат 9:16 (1080×1920).

> Статус: **правка проекта работает и проверена на реальном draft**. Готово:
> структура папок, выбор/расход файлов, замена медиа с сохранением
> свойств, синхронизация конца под озвучку, перестановка наложения (40–60%),
> удаление субтитров, фиксация шаблона субтитров, настройки, вкладка «Отстук».
> Осталось подключить **интерфейсные шаги** (автосубтитры, стиль/шрифт/шаблон
> кнопками, экспорт) — они настраиваются на машине пользователя.

---

## Как это работает (кратко)

1. Рядом с софтом создаётся папка **`Ассеты`** с подпапками — вы наполняете их
   файлами из проводника или из софта.
2. Вы указываете имя проекта CapCut и число роликов, жмёте «Запустить».
3. Софт по порядку **заменяет** нужные элементы в копии проекта (замена
   сохраняет скорость/громкость), синхронизирует конец под озвучку, переставляет
   видео-наложение, генерирует автосубтитры, применяет стиль/шрифт/шаблон и
   экспортирует ролик в папку **`Результат`** (1080p, 60fps, битрейт «Выше»).
4. Все действия пишутся в лог — вкладка **«Отстук»**, оттуда лог можно выгрузить
   в файл и прислать разработчику.

### Папки в `Ассеты`

| Папка | Что это | Поведение |
|---|---|---|
| `Музыка 1 (переход)` | звук перехода в начале | случайно |
| `Музыка 2 (перед наложениями)` | звук перед видео-наложением и перед фото | случайно |
| `Озвучка` | озвучка (музыка #3), задаёт длину ролика | берётся 1 раз и уходит |
| `Фон 1 (вступление)` | короткий вступительный игровой фон | берётся 1 раз и уходит |
| `Фон 2 (основной)` | основной игровой фон | берётся 1 раз и уходит |
| `Видео наложение` | видео-наложение в середине | случайно |
| `Результат` | сюда сохраняются готовые ролики | — |

«Берётся 1 раз и уходит»: использованный файл переносится в подпапку
`_использовано` внутри той же папки (не удаляется навсегда — так безопаснее).

Фоновая музыка и фото в конце берутся из **исходного проекта** и как контент не
заменяются (фоновую музыку софт только подрезает по длине под озвучку).

## Где взять и как запустить (Windows)

**Шаг 1. Скачать код.** На странице репозитория на GitHub нажмите зелёную
кнопку **Code → Download ZIP** (ветка `cursor/capcut-automator-scaffold-e2ac`)
и распакуйте в любую папку. Либо, если установлен git:

```bash
git clone -b cursor/capcut-automator-scaffold-e2ac <URL репозитория>
```

> ВАЖНО: сначала **распакуйте** ZIP в обычную папку (кнопка «Извлечь» в
> архиваторе) и запускайте `run.bat` из **проводника**. Не запускайте его
> изнутри архива (WinRAR/7-Zip) — иначе файлы распакуются во временную папку и
> ничего не сработает.

**Шаг 2а. Запуск двойным кликом (проще всего).**
Дважды кликните **`run.bat`**. При первом запуске он сам поставит Python-зависимости
и откроет приложение. Нужен установленный
[Python 3.11+](https://www.python.org/downloads/) (при установке отметьте
галочку **«Add Python to PATH»**).

**Шаг 2б. Собрать один `.exe` (чтобы потом запускать без Python).**
Дважды кликните **`build_exe.bat`** — через несколько минут в папке `dist`
появится **`CapCut Автомонтаж.exe`**. Его можно скопировать куда угодно;
рядом с ним создадутся папки `Ассеты`, `Результат` и логи.

> Готовый `.exe` собирается только на Windows (так работает PyInstaller),
> поэтому этот шаг выполняется у вас на компьютере, а не в облаке.

## Что прислать разработчику для калибровки

Чтобы включить правку проекта, нужен **реальный пример вашего проекта CapCut**.

### 1. Узнать версию CapCut
- Откройте CapCut → значок профиля/шестерёнка → «Настройки» → «О программе»
  (или «About»). Там указана версия.
- Либо: `Win+R` → вставьте `%LOCALAPPDATA%\CapCut\Apps` → Enter — имена папок
  обычно содержат номер версии.

### 2. Найти папку проекта (draft)
1. Нажмите `Win+R`.
2. Вставьте путь и нажмите Enter:
   ```
   %LOCALAPPDATA%\CapCut\User Data\Projects\com.lveditor.draft
   ```
3. Внутри — папки проектов. Найдите ту, чьё имя совпадает с названием вашего
   проекта в списке проектов CapCut. Если имён не видно — сортируйте по дате
   изменения и откройте ту, что менялась последней после сохранения проекта.
4. Внутри папки будут файлы вроде `draft_content.json`, `draft_info.json`,
   `draft_meta_info.json` и медиа.

### 3. Прислать JSON (без медиа — так меньше и без личных файлов)
- Достаточно **только `.json`-файлов** из папки проекта (медиа не нужны для
  разбора структуры).
- Заархивируйте их в zip и прикрепите в чат, либо пришлите содержимое
  `draft_content.json` / `draft_info.json`.

## Соответствие таймлайна (зафиксировано по проекту)

| Элемент | Где в проекте | Действие |
|---|---|---|
| Размытый фон | видео-дорожка с эффектом «Размытие» | замена |
| Передний фон (квадрат) | тот же ролик без блюра | замена |
| Фон 1 / Фон 2 | 1-й и 2-й сегменты фоновых дорожек | из папок, расход |
| Видео-наложение | сегмент с хромакеем | случайно, не режется, окно 40–60% |
| Фото в конце | сегмент-фото | не трогается |
| Озвучка (#3) | громкая аудио-дорожка на весь ролик | расход, задаёт длину |
| Свуш-переход (#1) | 1-й короткий звук | случайно |
| Звуки «Музыка 2» (#2) | звук перед наложением и перед фото | случайно (2 независимых) |
| Фоновая музыка | тихая аудио-дорожка на весь ролик | только длина |
| Субтитры | текст-дорожка (шаблон фиксируется) | удаляются, ASR заново |

Подтверждено: `Фон 1`/`Фон 2` расходуются; фоновая музыка и фото — из проекта;
удлинение — растягиванием ролика; размытый фон = тот же файл, что передний.

## Автосубтитры и экспорт (интерфейс CapCut)

Эти шаги делаются через интерфейс CapCut (правкой файла их не сделать). Они уже
реализованы как клики по **эталонным скриншотам кнопок** — это позволяет
настроить автоматизацию под вашу сборку/тему CapCut без изменения кода.

### Как включить
1. В «Настройках» → «Автосубтитры и экспорт» нажмите **«Открыть папку со
   скриншотами кнопок»**.
2. Положите туда PNG-скриншоты кнопок (аккуратно обрежьте каждую кнопку). Список
   ниже. Имена файлов — строго как указано.
3. В CapCut один раз задайте папку экспорта по умолчанию = ваша папка
   `Ассеты\Результат` (тогда софт будет только задавать имя файла).
4. Поставьте галочку **«Включить автосубтитры и экспорт»** и сохраните.
5. Запускайте как обычно — теперь софт после правки проекта сам сделает
   субтитры, стиль/шрифт/шаблон и экспорт (1080p/60fps/битрейт «Выше»),
   имя файла = `номер_дата`.

### Нужные скриншоты (папка «Интерфейс (скриншоты кнопок)»)
Обязательные: `project_tile.png` (плитка проекта), `menu_text.png` (кнопка
«Текст»), `auto_captions.png` («Автоматические субтитры»), `captions_generate.png`
(кнопка запуска распознавания), `template_button.png` («Шаблоны»),
`template_target.png` (нужный шаблон), `style_button.png` («Стиль»),
`style_white.png` (стиль без чёрных краёв), `font_search.png` (поиск шрифта),
`font_blok_1.png` (шрифт на «Блок»), `export_button.png` («Экспорт»),
`export_name_field.png`, `export_resolution.png`, `export_res_1080.png`,
`export_fps.png`, `export_fps_60.png`, `export_bitrate.png`,
`export_bitrate_high.png`, `export_confirm.png`.

Необязательные (улучшают надёжность): `editor_ready.png`, `captions_progress.png`,
`batch_edit.png`, `font_blok_2.png`, `font_blok_3.png`, `export_progress.png`.

При сбое софт сохраняет скриншот экрана в `logs\screenshots` и пишет понятное
сообщение в «Отстук» — по нему легко понять, на какой кнопке застряло.

> Пока галочка выключена (или не хватает скриншотов), софт делает только правку
> проекта и сохраняет его — субтитры/экспорт можно сделать в CapCut вручную.
