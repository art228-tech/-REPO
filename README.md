# Обработка TXT: дописать последнее предложение

Файл `process_txt.bat` — кидаете в папку с `.txt` и запускаете двойным щелчком. Откроется окно.

## Что делает

1. Берёт все `.txt` в **этой же папке** (без подпапок).
2. Сортирует по имени «по-человечески»: `1, 2, 9, 10`, а не `1, 10, 2, 9`.
3. **Первые 270 файлов не трогает** (число можно поменять в окне).
4. К остальным дописывает в конец **одно предложение** из списка. Несколько строк чередуются по кругу.
5. После работы пишет лог `_process_log_ДАТА.txt` в ту же папку.
6. Оригиналы кладёт в `_txt_backup`. Кнопка **«Вернуть всё как было»** копирует их обратно.

## Как пользоваться

1. Скопируйте `process_txt.bat` в папку с текстами.
2. Запустите двойным щелчком.
3. Введите предложения — каждое с новой строки.
4. Нажмите **Обработать файлы** и подтвердите.
5. Если что-то пошло не так — **Вернуть всё как было**.

Лог и бэкап появляются рядом с батником. Повторная обработка не затирает первый бэкап, поэтому откат всегда к состоянию до первой обработки.

## Настройки

Число пропускаемых файлов по умолчанию задаётся в начале `process_txt.bat`:

```bat
set "SKIP_COUNT=270"
```

В окне его тоже можно изменить. Не обрабатываются файлы логов `_process_log_*.txt` и `_restore_log_*.txt`.
