# TG Mailer Bot

Панель в Telegram-боте для рассылки с нескольких своих аккаунтов по одной базе контактов без дублей.

## Возможности

- Несколько аккаунтов (номер → код → 2FA)
- Прокси на каждый аккаунт отдельно
- Загрузка базы (txt / текст): телефон, @username или id
- Msg1 и Msg2 — по несколько вариантов, выбор случайный
- Пауза между Msg1 и Msg2
- Интервал между отправками **на один аккаунт**
- Живая статистика
- PeerFlood (спамблок): аккаунт отключается, остальные продолжают
- Стоп / продолжение с перепроверкой SB
- Выгрузка pending / sent / failed
- Логи в боте и на диске, состояние не сбрасывается

## Быстрый старт на сервере

1. Положи `BOT_TOKEN` в `/opt/tg-mailer/.env`
2. В боте: **Настройки → API_ID / API_HASH** (https://my.telegram.org)
3. Добавь аккаунты, базу, сообщения → Старт
