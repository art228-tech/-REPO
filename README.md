# ElevenLabs — промпты для молодого харизматичного голоса (быстрый темп)

Готовый пак для Voice Design: взрослый голос 22–26, энергия коротких вертикальных видео, без имён знаменитостей и без несовершеннолетних формулировок.

## Скачать ZIP

После пуша ветки файл будет здесь:

- внутри репозитория: [`dist/elevenlabs-shorts-voice-prompts.zip`](dist/elevenlabs-shorts-voice-prompts.zip)
- распакованная папка: [`elevenlabs-shorts-prompts/`](elevenlabs-shorts-prompts/)

Начни с карточки `01-male-hook-energy` или `07-female-hook-energy`, инструкция в `elevenlabs-shorts-prompts/HOW-TO.md`.
